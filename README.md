# syswatch-01

A custom Samsung/Wear OS watch face, built from a code-based SVG asset generator and a Watch Face Studio project.

| Directory | Purpose |
| --- | --- |
| `asset-generator` | The SVG/PNG generation code. |
| `watch-face` | The Samsung Watch Face Studio project. |
| `docs` | Specifications and implementation notes. |
| `references` | Concept images and visual references. |

## asset-generator layout

- `src` — generator source code.
- `scripts` — build and export scripts.
- `dist` — generated output: `svg`, `png`, and `previews`.
